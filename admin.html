Change admin password

Generates a slow-to-brute-force password hash (PBKDF2, 250,000 rounds) entirely in your browser — nothing is sent anywhere. Copy the output line over the ADMIN_PW_HASH constant near the top of assets/admin.js, commit, and the new password takes effect on next deploy. Use at least 10 characters.

Connection settings

This connects the admin page directly to your GitHub repo so publishing commits the change for you. Your token is stored only in this browser — never sent anywhere except GitHub's API. Use a fine-grained personal access token scoped to only this repo, with only "Contents: Read and write" permission — never a classic token with full account access. If this device is ever lost or compromised, revoke the token from GitHub's Developer Settings immediately.

Site analytics
